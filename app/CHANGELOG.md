# 更新记录

## 0.1.2 · 2026-10-13

- 修复部分 DeepSeek / 兼容接口将 DSML 检索指令作为正文返回时，被直接显示为回答的问题。
- 自动识别 DSML 与标准工具调用，执行当前聊天的搜索、上下文与统计后，继续生成正常 Markdown 回答。
- 保留工具轮次中的 reasoning_content，支持需要该字段的思考模型接口。
- 修复工具参数必填声明；校验关键词与消息编号，限制每轮工具数量和总检索轮次。
- 不完整指令会自动尝试重新整理一次；持续异常时显示可理解的错误提示，不显示内部指令。
- 旧版本保存的异常回复显示重新提问提示，并从下一次模型上下文中过滤。
- 升级继续使用原安装目录的聊天数据和模型配置。

验证：真实 ChatLab 引擎 + 本地模拟接口覆盖标准调用、三种 DSML 标签、多个工具、引用、截断、未知工具及重复调用。未使用个人聊天记录，未调用真实云端模型。

## 0.1.1 · 2026-10-13

### 新增与修复

- 模型回复按 Markdown 排版，支持标题、粗体、斜体、删除线、列表、任务清单、引用、分隔线、表格和代码块。
- 代码块展示语言并支持一键复制；宽表格和长代码可以横向滚动。
- 格式化后的聊天引用仍可点击查看原文；代码中的引用示例保留为代码。
- 支持用户点击 HTTP / HTTPS 链接，在浏览器打开；其他协议和含认证信息的链接不可打开。
- 模型输出经过 HTML 清理，脚本及事件处理程序不会执行；外部图片显示说明，不自动加载。
- Markdown 组件全部随软件打包，渲染不请求外部服务。导出报告和问答历史保留原始 Markdown。

### 验证

通过实际 Electron 界面的格式展示、复制、引用和危险内容拦截测试。测试使用虚构聊天记录与本地模拟模型，未调用真实云端模型。
