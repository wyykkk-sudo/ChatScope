# 更新记录

## 0.1.1 · 2026-10-13

### 新增与修复

- 模型回复按 Markdown 排版，支持标题、粗体、斜体、删除线、列表、任务清单、引用、分隔线、表格和代码块。
- 代码块展示语言并支持一键复制；宽表格和长代码可以横向滚动。
- 格式化后的聊天引用仍可点击查看原文；代码中的引用示例保留为代码。
- 支持用户点击 HTTP / HTTPS 链接，在浏览器打开；其他协议和含认证信息的链接不可打开。
- 模型输出经过 HTML 清理，脚本及事件处理程序不会执行；外部图片显示说明，不自动加载。
- Markdown 组件全部随软件打包，渲染不请求外部服务。导出报告和问答历史保留原始 Markdown。

### 验证

通过实际 Electron 界面的格式展示、复制、引用和危险内容拦截测试。测试使用虚构聊天记录与本地模拟模型，未调用真实云端模型。

## 0.1.0 · 2026-10-13

- 自动连接 Windows 微信 4.x，列出好友与群聊。
- 选中会话后自动准备记录并接入 ChatLab 分析。
- 大模型问答、关键词检索、证据引用、模型配置与报告导出。
